# Security policy

The script reads a public status page and sends messages with credentials you provide. Details of what leaves your machine and how secrets are handled: [docs/PRIVACY_AND_SECURITY.md](docs/PRIVACY_AND_SECURITY.md).

To report a vulnerability, open a private security advisory on the GitHub repository (Security tab, "Report a vulnerability"). Please do not post exploit details in a public issue.

Supported version: the latest 1.x release.
